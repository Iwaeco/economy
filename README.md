# ECOnomy

A web-based recipe breakdown and shop pricing tool for ECO (game).

## What It Does
* Breaks down crafting recipes so you can trace ingredients and costs.
* Helps figure out shop pricing for player-run stores.
* Runs locally in your browser from `ECOnomy.html` using data from `town_data.js` and assets from the `icons` folder.

## How to Run It
1. Keep `ECOnomy.html`, `town_data.js`, and the `icons` folder together in the same folder.
2. Open `ECOnomy.html` in your web browser.

## Notes
Built as a personal project to make pricing items and checking recipe chains easier while playing ECO (game). Recipes, town data, and icons may need updates as server settings or game versions change.
